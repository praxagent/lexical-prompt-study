# A196: supplied cue validity and canonical path preference

This fresh prospective experiment asks whether an explicit answer-column cue reverses conditional path preference when that cue conflicts with arithmetic truth. Both contexts instruct the model to copy the supplied fields. A foil-cue answer is therefore arithmetically wrong but instruction-compliant. The experiment measures a causal input contrast on full canonical-path probabilities, not free-generation success, a localized neural mechanism, a safety monitor or a learned detector. It does not replay or extend A195.

A positive M favors arithmetic truth in both contexts; it favors the instructed answer only in the true-cue context. The continuous primary is the equal-core mean of `M(true_cue) − M(foil_cue)` across all eight cores. It requires all sixteen margins. Any required missing margin leaves primary point/lower/upper null and `unbounded=true`; no complete-case estimate, finite missing-value bound or imputation is used.
